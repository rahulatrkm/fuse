How it works

Swipe, or use the arrow keys. Every tile slides as far as it can.

Two tiles with the same number fuse into one worth double. A tile that has already fused stands still for the rest of that move.

Time gives you three minutes. Daily is the same board for everyone, every day. Undo is always free.
